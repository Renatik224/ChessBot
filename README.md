# ♟️ Chess Bot

Chess Bot — программа для автоматической игры в шахматы с использованием шахматного движка **Stockfish**.

Программа распознаёт шахматную доску на экране, анализирует позицию и автоматически выполняет ходы с помощью мыши.

## 📦 Установка

1. Скачайте ZIP-архив проекта
2. Распакуйте архив в удобное место.
3. Убедитесь, что вместе с приложением находится файл шахматного движка `stockfish.exe`.
4. Запустите приложение `chess_bot.exe` который находиться в папке 'chess_bot\dist'.

**Важно:** не запускайте приложение непосредственно из ZIP-архива. Сначала полностью распакуйте его.

## ⚙️ Подключение Stockfish

Stockfish уже находится внутри ZIP-архива вместе с приложением. Скачивать его отдельно не требуется.

Чтобы подключить движок:

1. Запустите ChessBot.
2. Найдите раздел **Stockfish** в верхней части окна.
3. Нажмите кнопку **«Обзор…»**.
4. Откройте папку, в которую вы распаковали архив.
5. Найдите файл `stockfish.exe` и выберите его.
6. После выбора путь к движку появится в поле программы.

Теперь Chess Bot сможет использовать Stockfish для анализа шахматных позиций.

## 🎮 Как пользоваться

### 1. Выбор стороны

В разделе «За кого играю» можно выбрать:

- **Автоматически** — программа попытается определить вашу сторону самостоятельно.
- **Белые** — играть за белые фигуры.
- **Чёрные** — играть за чёрные фигуры.

### 2. Настройка силы игры

Можно настроить силу Stockfish:

- Уровень от 0 до 20.
- Ограничение по Elo.
- Готовые пресеты: Новичок, Любитель, Сильный и Максимум.

### 3. Настройка времени

- **Думать над ходом** — сколько секунд движок анализирует позицию перед ходом.
- **Пауза после хода соперника** — задержка перед следующим действием бота.

### 4. Дополнительные настройки

- **Потоки (Threads)** — количество потоков процессора, используемых движком.
- **Память Hash** — объём оперативной памяти, выделяемой под хеш-таблицу Stockfish.

### 5. Выбор шахматной доски

1. Нажмите кнопку **«Выбрать доску»**.
2. Экран затемнится.
3. Зажмите левую кнопку мыши и выделите квадратную область по границам шахматной доски.
4. Отпустите кнопку мыши.

Старайтесь выделять доску максимально точно, не захватывая лишние области.

### 6. Запуск

После настройки нажмите **«Старт»**.

Доступны три основные кнопки:

- ▶ **Старт** — запуск бота.
- ⏸ **Пауза** — временная остановка работы.
- ■ **Стоп** — завершение работы бота.

## 🔄 Продолжение уже начатой партии

Если партия уже началась, установите галочку:

**«Партия уже идёт (продолжить с текущей позиции)».**

Для этого режима необходимы сохранённые шаблоны фигур, полученные при предыдущем запуске бота на начальной позиции.

## 🚨 Аварийная остановка

Если бот ведёт себя неправильно или необходимо немедленно остановить его, переместите курсор мыши в любой угол экрана.

Это активирует встроенную функцию аварийной остановки PyAutoGUI.

## 💾 Сохранение настроек

Программа автоматически сохраняет настройки, включая путь к Stockfish, параметры силы игры и другие значения.

При следующем запуске сохранённые настройки будут загружены автоматически.

## 🛠️ Используемые технологии

- Python
- Stockfish
- OpenCV
- python-chess
- PyAutoGUI
- MSS
- NumPy
- Tkinter

## ⚠️ Примечания

- Для корректной работы шахматная доска должна быть видна на экране.
- Не закрывайте доску другими окнами во время работы бота.
- При первом запуске рекомендуется использовать начальную позицию партии.
- Точность распознавания зависит от внешнего вида шахматной доски и фигур.
